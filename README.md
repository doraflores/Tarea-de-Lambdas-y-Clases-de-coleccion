# Tarea Lambdas Java
## Descripción
Proyecto que demuestra el uso de expresiones lambda, Streams y colecciones de Java.

## Métodos implementados
- Multiplicador
- Filtro Selectivo
- Conversor de Mayúsculas
- Cuadrados Únicos
- Mapa de Longitudes
- Modificador de Inventario
- Contador de Frecuencias
- Clasificador de Palabras
- Deduplicación de Palabras
- Tope de Frecuencias
## Compilación
javac *.java

## Ejecución
java Main
